# Charlizi Factory — robots.txt
# Single, authoritative policy. Do NOT duplicate User-agent blocks.
#
# ⚠️ READ THIS BEFORE EDITING
# Crawlers honour only the FIRST group that matches their user-agent, and they
# stop reading that group at the FIRST blank line. A `Disallow: /` placed above
# a later `Allow: /` for the same bot silently wins. A Disallow line that is
# separated from its User-agent by a blank line belongs to NOBODY and is
# silently ignored by every crawler.
#
# Therefore: every group below is kept tight (User-agent + directives, then one
# blank line). Group-specific rules MUST sit inside their own group. Do not
# append a stray `Disallow:` after a blank line — it will be dropped.
#
# This file targets the GEO / AI-answer-engine channel deliberately:
# AI search bots must be ALLOWED so Charlizi content can be cited in
# ChatGPT Search, Perplexity, Copilot, Gemini and Google AI Overviews.
# Pure *training* crawlers are denied, matching Content-Signal ai-train=no.
#
# If the live response starts with "# BEGIN Cloudflare Managed content",
# that block is injected by Cloudflare Bot Preference Sync and sits ABOVE this
# file, overriding everything below. Disable Bot Preference Sync to keep this
# file authoritative.
